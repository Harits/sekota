# Merchandise Implementation Requirements

## 🧱 Component Breakdown

### 1. Header
- Main title: "Merchandise".
- Description text about the collection.

### 2. Sidebar Filter
- **Search**: Text input.
- **Sort by**: Dropdown.
- **Category**: Checkbox list (All, T-Shirt, Pin, Sticker, Others).
- **CTA Card**: "Customize Solution" with "Contact Us" button.

### 3. Grid View
- 3 columns.
- **Card**:
  - Item Image.
  - Rating (Stars).
  - Title.
  - Subtitle/Collection name (e.g., "THE URBAN COLLABORATOR").
  - "View Details" link.

### 4. Pagination
- Numeric pagination.
